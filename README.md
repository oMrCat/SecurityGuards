# SecurityGuards

一个基于 MFC 的 Windows 桌面系统工具，提供进程、线程、模块、窗口和服务查看，以及基础清理、PE 文件解析与规则扫描能力。

## 当前功能

- 查看系统窗口、进程、线程、模块和服务信息。
- 在状态栏显示 CPU 与物理内存使用率，并支持按进程工作集进行内存优化。
- 扫描指定目录中的 Visual Studio 构建残留；清理时仅处理用户勾选的文件。
- 分析 PE 文件的头、区段、导入/导出表、资源、重定位、延迟加载和 TLS 信息。
- 按 MD5 或本地黑名单规则扫描单个文件或目录，并显示命中项；删除命中项必须由用户手动点击。
- 通过 `Ctrl + Shift + H` 隐藏或恢复主窗口。

## 构建与运行

1. 使用 Visual Studio 2019 或更高版本安装“使用 C++ 的桌面开发”工作负载及 MFC 组件。
2. 打开 `MFCTaskList/MFCTaskList.sln`，选择 `Debug|Win32` 或 `Release|Win32` 后构建运行。
3. 若使用本地规则扫描，请保留项目中的 `LocalVirBase/Vir.ini`；程序会在可执行文件目录及其父目录中查找它。示例规则仅用于演示。

## 使用说明与边界

- 云端规则服务默认连接 `127.0.0.1:1234`，且采用项目原有的固定长度数据协议。服务不可用时扫描会安全取消，不会把空规则库当作扫描结果。
- 目录扫描会跳过重解析点，避免因符号链接或联接造成递归循环。
- “关机、重启、注销、休眠、清空回收站”和文件删除都会要求确认；请在理解影响后操作。
- 该项目是学习性质的系统工具，MD5 与路径黑名单只能作为基础规则匹配，不能替代专业、持续更新的安全防护软件。

## 目录

- `MFCTaskList/`：MFC 客户端工程。
- `MFCTaskList/LocalVirBase/Vir.ini`：本地示例规则库。
- `md5_value.sql`：服务端规则数据示例。
- `Server.zip`：原始配套服务端代码归档。
